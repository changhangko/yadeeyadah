# Architectural diagram conventions

Implemented on the website in October 2026 following the user's request.

## References studied

- User-supplied exploded axonometric house: warm walls, clay roof / ground, pale context, fine alignment guides.
- [ArchDaily diagram collection](https://www.archdaily.com/tag/diagrams) and [disassembled axonometry](https://www.archdaily.com/1037623/decomposition-as-expression-disassembled-axonometry-as-design-tool): expose the layers that explain the design.
- [Illustrarch structural diagram article](https://illustrarch.com/articles/architectural-diagrams/27053-understanding-architectural-structural-diagrams.html): distinguish elements, connections and explanatory annotations.
- [Sasaki / Bonnet Springs Park](https://www.sasaki.com/projects/bonnet-springs-park/): keep surrounding context subordinate to the site, landscape and routes.
- [BIG / 8 House](https://big.dk/projects/8-house-2021) and [BIG's published diagram](https://www.archdaily.com/83307/8-house-big/8h_diagram-by-big_11): show legible form changes and programme layers.

These inform conventions, not copied project geometry. Reference images are not deployed.

## Site application

- Drawing plates use warm paper, dark fine outlines and pale context.
- Ochre denotes building mass / inputs; terracotta denotes routes, parameters and separated layers; sage denotes open space or selected / processed elements; slate denotes connections and city data.
- Legends are specific to SPACE, SYSTEM, CODE and OBSERVATION rather than implying the same content in each category.
- SPACE uses one parallel projection and site across four stages. The final roof plate lifts along guides.
- Facade stages sample one ruled surface. Seven stages distinguish reference, levels, edge, vectors, interpolation, seams and panels.
- TODAI uses layered axonometry and a coloured route plan. Roof separation is a visual explanation; it does not alter gross floor area.
- Photography keeps original images; selection marks do not recolour photographs.
- Replay / static controls remain available. All added assembly motions are finite and respect reduced motion.

The model data remain schematic and labelled. No new research metrics or fabrication claims are introduced.
